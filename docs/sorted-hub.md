# Sorted hub — 22 November 2026

- `sor7ed.com` is the main hub for the company, products and central membership.
- `/links` is the customer page for SOR7ED Links, pronounced Sorted Links. Use
  the original white scribble, yellow `#FFBA2E` Anton LINKS, and
  “See it. Send it. SOR7ED.” The customer installation path is Chrome Web Store,
  not a developer ZIP. Its public sharing image is `/links-preview.png`.
- `/about` explains the company and vision; `/about#vision` is the vision link.
  This replaces the old cross-domain redirect for `/about` only.
- `/signin` and `/account` remain the existing central member routes. No new
  account system, login transport, database or delivery path is introduced.
- Planet Sorted remains the separate public website for tools and guidebooks.
  There is no Planet Sorted member login. Existing redirects for its other
  content routes stay intact, and Notion publication is unchanged.
- Members can request supported protocols and keep links/protocols in WhatsApp
  and their saved library. Public guide reading and tool explanations stay open.
- Saved interactive tool results were suggested as a possible future member
  perk. They are not advertised as available or implemented by this change.

The home demo and existing Button information remain available below the hub.
The extension source and upload-ready v0.2.7 package are in `extension/`; its
store title/summary and separately editable full listing copy are documented
there. Publishing the website does not approve or publish a Chrome Store update.
